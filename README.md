# 🛡️ SafeGuard UA

**Моніторинг рівнів тривог та небезпек України в реальному часі.**

Вебзастосунок (PWA) з темною мапою, який показує поточні рівні тривоги — 🔴 ракетна
небезпека та 🟡 наліт БПЛА — по областях, районах і громадах, озвучує загрози
українською та попереджає про небезпеку у вашому регіоні.

> ⚠️ **Не є офіційним джерелом оповіщення.** Дані беруться з публічного API
> [alerts.in.ua](https://alerts.in.ua). У критичній ситуації завжди керуйтеся
> офіційними каналами: сирена, ДСНС, місцеві органи влади.

**Версія:** 2.7 Beta · Glass HUD

| Можливість | Опис |

| Зведення для Telegram | Кнопка копіювання оперативного зведення у буфер обміну |
| PWA | Встановлення на телефон (PNG-іконки 192/512/maskable), офлайн-кеш важких GeoJSON |
| Контроль достовірності | Стани «онлайн / дані застарілі / немає зв'язку» з банером і ручним повтором |
| Енергозбереження | Пауза опитування у фоновому режимі (Visibility API) та експоненційний backoff |

## Структура проєкту

```
SafeGuard UA/
├─ index.html               # увесь UI та логіка застосунку (v2.7 Beta)
├─ server.py                # локальний сервер + проксі до alerts.in.ua (обхід CORS)
├─ sw.js                    # Service Worker: network-first для HTML, cache-first для GeoJSON
├─ manifest.json            # PWA-манифест
├─ start.bat                # запуск сервера на Windows
├─ ukraine_regions.geojson  # контури областей (~180 КБ)
├─ ukraine_rayony.geojson   # контури районів (~1 МБ)
├─ ukraine_hromady.geojson  # контури громад (~3,3 МБ)
├─ icons/                   # PNG-іконки PWA (192, 512, maskable, apple-touch)
├─ .gitignore
├─ README.md
└─ _legacy/                 # архів старих генераторів (у .gitignore, не публікується)
```

`index.html` — **єдине джерело правди** для UI та клієнтської логіки.
Python-генератори, які раніше перезаписували цей файл, переміщено в `_legacy/`
і запускати їх **не потрібно**.

## Локальний запуск

Потрібен Python 3.8+ (зовнішніх бібліотек немає).

```bash
# з кореня проєкту
python server.py
# або на Windows: двічі клікнути start.bat
```

Відкрийте <http://localhost:8080/>.

Сервер виконує дві функції:

1. віддає статичні файли проєкту;
2. проксює `GET /api/alerts` → `https://api.alerts.in.ua/v1/alerts/active.json`,
   щоб браузер не впирався в CORS.

### Токен API

Токен **не зберігається ні в `index.html`, ні в `server.py`**. Сервер шукає його
в такому порядку:

```bash
# 1) змінна середовища
set ALERTS_API_TOKEN=ваш_токен          # Windows (cmd)
export ALERTS_API_TOKEN=ваш_токен       # Linux/macOS

# 2) локальний файл token.txt у корені проєкту (внесений у .gitignore)
echo ваш_токен > token.txt

# 3) параметр запиту — лише для ручної діагностики
http://localhost:8080/api/alerts?token=ваш_токен
```

Клієнт звертається до `/api/alerts` **без** токена. Якщо токена немає — сервер
відповідає `503` з `{"stale": true}`, і застосунок показує стан «немає даних»,
а не вигадані тривоги.

## Деплой

### GitHub Pages

1. Запуште репозиторій (корінь проєкту).
2. *Settings → Pages → Source: Deploy from a branch → `main` / `(root)`*.
3. Сайт буде доступний за адресою `https://<user>.github.io/<repo>/`.

### Як обирається джерело даних

| Ситуація | Куди йде запит |
|---|---|
| Продакшн (github.io або будь-який хост) | **Cloudflare Worker** — `WORKER_PROXY_URL` |
| Локально (`localhost` / `127.0.0.1`), Worker недоступний | fallback на `server.py` → `/api/alerts` |
| Відкрито як `file://` | тільки Worker (локального проксі немає) |

Worker — **основне** джерело: він проксює `alerts.in.ua` і додає заголовок
`Authorization: Bearer <token>` зі своїх секретів. Локальний `server.py`
залишається резервом для офлайн-тестування на localhost і ніколи не
використовується на github.io.

### Cloudflare Worker (приклад)

```js
export default {
  async fetch(request, env) {
    const upstream = 'https://api.alerts.in.ua/v1/alerts/active.json?token=' + env.ALERTS_API_TOKEN;
    const resp = await fetch(upstream, {
      headers: { 'Authorization': 'Bearer ' + env.ALERTS_API_TOKEN, 'Accept': 'application/json' }
    });
    return new Response(resp.body, {
      status: resp.status,
      headers: {
        'Content-Type': 'application/json; charset=utf-8',
        'Cache-Control': 'no-store',
        // Сторінка на github.io звертається з іншого origin — без цього заголовка браузер заблокує відповідь
        'Access-Control-Allow-Origin': '*'
      }
    });
  }
};
```

Токен зберігається як Secret Worker'а (`ALERTS_API_TOKEN`), а не в репозиторії.

## Історія загроз

Клік по області, району або громаді на карті відкриває панель із хронологією за
останні 24 години: час початку та відбою, тип загрози (ракети / шахеди / арта),
тривалість кожної події.

> **Важливо:** історія збирається **локально на пристрої** зі спостережень за
> відповідями API (журнал у `localStorage`, ключ `safeguard_history_v1`). Для
> тривог, активних на момент відкриття застосунку, час початку береться з поля
> `started_at`, тому вони з'являються у таймлайні одразу. Події, що відбулися до
> першого запуску на цьому пристрої, не відображаються — для повної серверної
> історії потрібно додати в проксі ендпоінт `alerts/{uid}/history`.

## Стани достовірності даних

Застосунок свідомо **не показує «все спокійно», якщо даних немає**:

| Стан | Умова | Що бачить користувач |
|---|---|---|
| `online` | успішна відповідь API, дані молодші 90 с | «СИСТЕМА ОНЛАЙН», звичайний вигляд |
| `stale` | 429 від API, прапорець `stale` у відповіді або дані старші 90 с | жовтий банер «Немає свіжих даних з HH:MM» |
| `stale` (старий payload) | усі тривоги мають `updated_at` старший 24 год — проксі віддає кеш | жовтий банер із датою, коли джерело востаннє оновлювалося |
| `offline` | мережева помилка / таймаут / 5xx | червоний банер «Немає зв'язку…» + кнопка «↻ Повторити» |
| немає даних | жодної успішної синхронізації | «⚪ НЕВІДОМО» замість «БЕЗПЕЧНО», прочерки в лічильниках |

Перевірка вручну: відкрийте DevTools → *Network* → **Offline** і подивіться, що
статус змінюється на «НЕМАЄ ЗВ'ЯЗКУ», а картка регіону — на «⚪ НЕВІДОМО».
Після повернення онлайну все відновлюється без перезавантаження.

## Джерела даних

| Дані | Джерело |
|---|---|
| Активні тривоги, рівні, типи загроз | [alerts.in.ua API v1](https://devs.alerts.in.ua/) |
| Сейсмічні події | [USGS FDSN Event API](https://earthquake.usgs.gov/fdsnws/event/1/) |
| Контури областей / районів / громад | [slawomirmatuszak/ukrainian_geodata](https://github.com/slawomirmatuszak/ukrainian_geodata) |
| Тайли карти | Esri World Dark Gray (Canvas) |

Оновлення списку тривог: кожні 20 с у активній вкладці, кожні 2 хв у фоновому
режимі (Visibility API), з експоненційним backoff до 5 хв при серії помилок.
Сейсміка — при старті та ручному оновленні.

## Архів `_legacy/`

Тут зібрано те, що більше не використовується, але може знадобитися для історії:

- `build_html.py`, `build_clean_index.py`, `build_full_mobile_index.py`,
  `build_updated_index.py`, `generate_index.py`, `patch_html.py` — старі генератори
  `index.html` (різні версії UI; запуск будь-якого зіпсує актуальний `index.html`);
- `alerts_snapshot.json` — застарілий зріз тривог від 29.10.2023;
- `regions_min.json` — проміжний артефакт генераторів;
- `.github/` — стара копія сайту з вбудованим зрізом 2023 року.

Каталог внесено в `.gitignore`, тому він не потрапляє ні в репозиторій, ні в
GitHub Pages. Видалити його можна в будь-який момент:

```bash
rm -rf _legacy        # Linux/macOS
rmdir /s /q _legacy   # Windows cmd
```
